# PNP AI - Image & Meme Generative AI

A powerful web application that uses Stable Diffusion to generate images and memes from text prompts.

## Features

- 🎨 Generate high-quality images from text descriptions
- 🚀 Fast and efficient AI processing
- ⚙️ Customizable generation parameters
- 📱 Responsive design
- 💾 Download generated images
- 🎯 User-friendly interface
